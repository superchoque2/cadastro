# Cadastro de Clientes 📋

Exercício de lógica de programação em Python, praticando **funções**, **escopo de variáveis**, **listas** e **dicionários** — estruturas fundamentais que também são usadas no dia a dia de desenvolvimento backend.

## 💡 Sobre o projeto

Programa em Python que simula um cadastro simples de clientes, armazenando os dados em memória (sem banco de dados ainda). Cada cliente é representado por um **dicionário**, e todos os clientes cadastrados ficam guardados em uma **lista**.

Ao final do cadastro, o programa analisa os dados e informa:
- Quantos clientes são maiores de idade e quantos são menores
- O nome do cliente mais velho cadastrado

## 🎯 Conceitos praticados

- Funções (`def`) e retorno de valores (`return`)
- Escopo de variáveis (local vs. global)
- Listas e dicionários (estruturas de dados compostas)
- Laços de repetição (`for`)
- Estruturas condicionais (`if` / `else`)
- Variáveis acumuladoras (contadores)

## 🛠️ Como funciona

1. O programa pergunta quantos clientes serão cadastrados
2. Para cada cliente, solicita: nome, idade, sexo e data de nascimento
3. Cada cliente é armazenado como um dicionário dentro de uma lista
4. Ao final, o programa percorre a lista para:
   - Contar quantos clientes são maiores/menores de idade (18+)
   - Identificar o nome do cliente mais velho
